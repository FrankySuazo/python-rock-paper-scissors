# ✊✋✌️ Rock Paper Scissors

A command-line Rock Paper Scissors game developed in Python. Play against the computer and see who wins!

## Features

- Choose Rock, Paper, or Scissors.
- Computer randomly selects its move.
- Determine whether the player wins, loses, or ties.
- Display selections using emojis.
- Validate numeric choices outside the allowed range.

## Technologies Used

- Python 3
- `random` module
- Dictionaries
- Conditional statements (`if`, `elif`, `else`)
- Logical operators (`and`, `or`)

## How to Run

Clone the repository:

```bash
git clone https://github.com/FrankySuazo/python-rock-paper-scissors.git
```

Navigate into the folder:

```bash
cd python-rock-paper-scissors
```

Run the game:

```bash
python rock_paper_scissors.py
```
